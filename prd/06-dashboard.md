## 1. 목적

작업 공간의 영업 현황을 숫자로 요약한다. MVP의 집계는 두 가지, **단계별 금액 합계**와 **수주율**이다. 백엔드 관점에서는 "집계 수치가 파이프라인·상세 화면의 개별 값과 항상 일치한다"가 핵심이다. 화면은 단순해도 되고, 수치의 정의와 정확성이 중요하다.

## 2. 유저 스토리

- US-DB-1. 영업 담당자로서, 단계별로 얼마가 걸려 있는지 한눈에 보고 싶다. 이번 분기 전망을 가늠하기 위해.
- US-DB-2. 영업 담당자로서, 마감된 건 중 얼마나 수주했는지 비율로 보고 싶다. 영업 효율을 점검하기 위해.
- US-DB-3. 방문자로서, 칸반에서 카드를 옮기면 대시보드 수치가 바로 바뀌는 것을 보고 싶다. 데이터가 연결되어 있음을 확인하기 위해.
- US-DB-4. 영업 담당자로서, 오늘 처리할 할 일과 지연된 건을 대시보드에서 바로 보고 싶다. 하루를 시작하는 화면으로 쓰기 위해.

## 3. 인수조건

### 3.1 집계 정의

- [ ] `AC-DB-01` [BE] 대시보드 요약 조회는 한 번의 요청으로 아래를 모두 돌려준다: 열린 단계별 건수·금액 합계, 열린 건 전체의 건수·금액 합계, 수주 건수·금액, 실패 건수·금액, 수주율(`AC-DB-03`), 지연된 열린 건 수(예상 마감일 경과), 미완료 할 일 수(05 포함 시).
- [ ] `AC-DB-02` [BE] 단계별 금액 합계는 **그 단계에 현재 있는 열린 Opportunity의 금액 합**이다. 종료된 건은 어느 열린 단계에도 포함되지 않는다. 04의 파이프라인 열 머리 합계(`AC-OP-21`)와 같은 규칙·같은 값이다.
- [ ] `AC-DB-03` [BE] 수주율은 **건수 기준, 종료 건 기준**이다: 수주율 = 수주 건수 ÷ (수주 건수 + 실패 건수). 열린 건은 분모에 들어가지 않으므로 열린 건의 생성·삭제·열린 단계 사이 이동으로는 수주율이 바뀌지 않는다. 분모가 0이면(종료된 건이 하나도 없으면) 수주율은 "계산 불가"로 돌려주고 FE는 0%로 보이지 않게, 계산할 수 없음이 드러나도록 표시한다. **검증 예**: 수주 3·실패 1이면 75%, 수주 0·실패 2면 0%, 수주 0·실패 0이면 계산 불가.
- [ ] `AC-DB-04` [BE] 집계는 조회 시점의 데이터를 반영한다. 단계 변경·생성·삭제 직후 다시 조회하면 변경이 즉시 반영된다. (캐시 등 구현은 사용자 결정. 반영 지연이 생기면 그 사실을 ADR로 남긴다)
- [ ] `AC-DB-05` [BE] **정합성 검증**: 임의의 작업 공간에서 (a) 대시보드 단계별 합계의 총합 = 열린 건 전체 금액 합계, (b) 열린 건 수 + 수주 건 수 + 실패 건 수 = 전체 Opportunity 수, (c) 각 단계 합계 = 그 단계 Opportunity를 개별 조회해 더한 값. 세 가지가 예시 데이터와 임의 조작 후 모두 성립한다. (자동 테스트로 남긴다)
- [ ] `AC-DB-06` [BE] 집계는 요청한 작업 공간의 데이터만 포함한다. 다른 작업 공간에 데이터가 아무리 많아도 수치에 영향이 없다. (`AC-WS-26`과 함께 검증)
- [ ] `AC-DB-07` [BE] 집계 대상 Opportunity가 0건이어도(예시 데이터 전부 삭제) 오류 없이 모두 0 또는 "계산 불가"로 돌려준다.

### 3.2 화면

- [ ] `AC-DB-08` [FE] 대시보드는 다음을 보여 준다: (1) 단계별 금액 합계 (막대 또는 깔때기 형태, 단계 순서대로), (2) 수주율과 수주/실패 건수, (3) 열린 건 전체 금액·건수, (4) 지연된 건 수, (5) 미완료 할 일 목록 또는 수(05 결정에 따라).
- [ ] `AC-DB-09` [FE] 단계별 막대를 누르면 그 단계로 걸러진 파이프라인으로 이동한다.
- [ ] `AC-DB-10` [FE] 수주율 수치 옆에 계산 기준 라벨 **"종료 건 기준 · 건수"** 가 짧게 표시된다. 방문자가 숫자의 뜻을 오해하지 않도록. (문구의 시각 처리는 designer가 정하되 뜻은 유지한다)
- [ ] `AC-DB-11` [FE] 대시보드 차트의 색·형태는 자체 디자인 토큰을 따른다 (`AC-COMMON-07`).

### 3.3 공통

- [ ] `AC-DB-12` [BE] 만료된 작업 공간의 대시보드 조회는 `AC-COMMON-03`에 따라 거부된다.

## 4. 제외 범위

- 기간 필터(이번 달·분기), 기간별 추이 그래프
- 담당자별·거래처별 집계
- 예측(가중 파이프라인, 포캐스트)
- 대시보드 위젯 커스터마이징, 내보내기(CSV·이미지)
- 목표 대비 달성률
- 금액 기준 수주율(수주 금액 ÷ 종료 건 금액)의 표시. 수주율은 건수 기준 하나만 둔다 (`AC-DB-01`의 수주·실패 금액은 수치로만 보인다)
- 전체 Opportunity 수를 분모로 하는 수주율

## 5. 의존성 / 열린 질문

- `AC-DB-08`의 차트 축은 04 §3.2의 열린 단계 세 개(발굴·제안·협상) 순서다.
- "지연된 건"의 기준일은 서버 시각 기준 "오늘"로 하되, 시간대 처리는 API 계약에서 정한다.
