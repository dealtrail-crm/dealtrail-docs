## 배경

비밀번호 규칙은 테스트 계정 대여 비밀번호와 회원 비밀번호가 공유한다. 두 흐름({{B03}}, {{B35}})보다 먼저 분리해 둔다. 저장 방식(해시 알고리즘 등)은 사용자가 정한다.

- Epic: {{E1}}
- 선행: 없음
- 설명 포인트: 없음

## 유저 스토리

- `US-WS-1` 방문자로서, 개인정보 없이 비밀번호만 정해 체험을 시작하고 싶다.
- `US-MB-1` 방문자로서, 아이디·비밀번호만으로 가입하고 싶다.

## 인수조건

- [ ] `AC-COMMON-10` 비밀번호는 8자 이상이고 구성 제한이 없다 (BE: 8자 미만 거부, `AC-COMMON-05` 형식 / FE 규칙 표시는 {{F01}} {{F22}}). 테스트 계정·회원에 같은 규칙을 적용한다
- [ ] `AC-COMMON-11` 비밀번호 원문을 저장하지 않는다. 저장된 값으로 원문을 복원할 수 없음을 테스트로 확인한다
