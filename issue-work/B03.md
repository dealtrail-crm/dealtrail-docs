## 배경

테스트 계정 풀(기본 5개)에서 빈 계정에 비밀번호를 정하는 요청이 성공한 순간 그 계정은 대여 시간(기본 24시간) 동안 대여 상태가 된다. 대여 경쟁 포인트의 기반 이슈다. 대여를 계정 행의 컬럼으로 둘지 별도 행으로 둘지는 {{B13}}의 ADR과 함께 정한다.

- Epic: {{E1}}
- 선행: {{B01}}, {{B02}}
- 설명 포인트: 테스트 계정 동시 대여 경쟁 (기반). 핵심 이슈는 {{B04}}

## 유저 스토리

- `US-WS-1` 방문자로서, 이메일이나 이름을 내지 않고 체험을 시작하고 싶다.
- `US-WS-4` 방문자로서, 이 계정이 언제까지 내 것인지 알고 싶다.

## 인수조건

- [ ] `AC-WS-01` 테스트 계정은 미리 만들어진 고정 개수(기본 5개)이며 개수는 코드 변경 없는 설정값이다. 각 계정은 대여 중/빈 상태를 가진다
- [ ] `AC-WS-03` 빈 계정에 비밀번호(`AC-COMMON-10`)를 정하는 요청이 성공한 순간 대여가 시작되고 세션({{B01}})이 발급된다. 만료 시각(시작 시각 + 대여 시간)은 이 시점에 기록된다
- [ ] `AC-WS-29` 대여 만료 시각 = 시작 시각 + 대여 시간. 대여 시간은 코드 변경 없는 설정값이며 기본값은 24시간. 만료 시각을 FE가 조회할 수 있다 (세션 조회 응답, {{C1}})

## 비고

계정 수·대여 시간은 코드 변경 없는 설정값이다(기본 5개·24시간). 시연 환경에서는 대여 시간을 정리 주기({{B13}})와 함께 분 단위로 짧게 두어 대여 → 만료 → 정리를 실시간으로 보여 준다. 설정 방식(프로퍼티·환경 변수 등)과 시연용 값은 사용자가 정한다.
