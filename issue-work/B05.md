## 배경

대여 중인 계정의 로그인 규칙과, 모든 계정이 대여 중일 때의 응답·운영 로그를 다룬다. 대여 경쟁 포인트의 주변 이슈다.

- Epic: {{E1}}
- 선행: {{B03}}
- 설명 포인트: 테스트 계정 동시 대여 경쟁 (주변). 핵심 이슈는 {{B04}}

## 유저 스토리

- `US-WS-6` 방문자로서, 테스트 계정이 모두 사용 중이면 언제 다시 오면 되는지 알고 싶다.
- `US-WS-7` 운영자로서, "모두 사용 중"이 얼마나 자주 생기는지 알고 싶다.

## 인수조건

- [ ] `AC-WS-04` 대여 중인 계정에 다른 비밀번호로 로그인하면 거부된다. 빈 계정에는 비밀번호 설정 없는 로그인이 없다
- [ ] `AC-WS-07` 모든 계정이 대여 중이면 "모두 사용 중"과 **가장 이른 만료 시각**을 응답한다 (BE / FE 안내는 {{F01}})
- [ ] `AC-WS-08` "모두 사용 중"으로 대여가 실패할 때마다 발생 시각과 가장 이른 만료 시각이 로그로 남는다
- [ ] `AC-WS-10` 테스트 계정 세션은 대여 만료 시각까지 유지된다. 로그아웃해도 대여·데이터는 유지되고 같은 비밀번호로 만료 전 재로그인할 수 있다 (BE / FE는 {{F02}})
- `AC-WS-09` 비밀번호 찾기·변경 기능이 **없음**을 확인한다 (제공하지 않는 것이 요구사항)
