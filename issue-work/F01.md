## 배경

방문자가 첫 화면에서 "체험하기"를 눌러 개인정보 없이 테스트 계정 비밀번호를 정하고 시작하는 화면이다. 빈 계정 진입 방식(목록 / 자동 배정)은 designer 결정을 따른다.

- Epic: {{E1}}
- 선행: {{C1}} 승인 (정적 부분은 계약 전에 가능)
- 설명 포인트: 없음

## 유저 스토리

- `US-WS-1` 방문자로서, 이메일이나 이름을 내지 않고 체험을 시작하고 싶다.
- `US-WS-6` 방문자로서, 테스트 계정이 모두 사용 중이면 언제 다시 오면 되는지 알고 싶다.

## 인수조건

- [ ] `AC-WS-02` 첫 화면에 "체험하기" 진입점이 있고, 누르면 테스트 계정 진입 화면으로 간다. 이메일·이름 등 개인정보 입력이 없다
- [ ] `AC-WS-07` 모두 사용 중이면 체험 계정이 모두 사용 중임과 가장 빨리 비는 시각을 알리고, 회원가입 진입점을 보여 준다 (FE / BE 응답은 {{B05}})
- [ ] `AC-WS-09` 비밀번호를 정하는 화면에 비밀번호 찾기·변경이 없고 잊으면 만료 시각에 자동 반납됨을 안내한다 (FE 안내)
- [ ] `AC-COMMON-10` 입력란 옆에 비밀번호 규칙(8자 이상, 구성 제한 없음)을 표시한다 (FE / BE 검증은 {{B02}})
- 대여 요청은 브라우저가 `/api`를 직접 호출한다 (Next.js 서버 경유 금지, {{C0}})
