## 배경

Contact 생성·수정·목록 API. 소속 Account는 같은 작업 공간의 것만 선택 가능하고 생성 후 바꿀 수 없다. Epic 4가 의존하므로 `priority:high`. 다른 작업 공간 Account 지정 거부는 {{B11}} 경유로 성립한다.

- Epic: {{E3}}
- 선행: {{B19}}
- 설명 포인트: 없음

## 유저 스토리

- `US-ACC-2` 영업 담당자로서, 담당자를 직접 등록하고 싶다.
- `US-ACC-3` 영업 담당자로서, 담당자 정보를 고치고 싶다.

## 인수조건

- [ ] `AC-CT-01` Contact는 이름(필수), 소속 Account(필수), 상태(재직 중/퇴사), 이메일, 전화, 직함, 메모를 가진다 (BE / FE 폼은 {{F13}})
- [ ] `AC-CT-03` 직접 생성·수정할 수 있다. 소속 Account는 같은 작업 공간의 Account만 가능하고, 다른 작업 공간의 Account는 "존재하지 않음"으로 거부된다 (BE)
- [ ] `AC-CT-04` 소속 Account 변경 요청은 `AC-COMMON-05` 형식으로 거부된다 (BE)
- [ ] `AC-COMMON-04` 목록은 페이지네이션·이름/회사명 검색을 지원하고 행별 소속 Account·상태를 포함한다 (`AC-CT-02`의 BE 부분)
