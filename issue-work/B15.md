## 배경

Lead 상태(신규·진행 중·검증됨·전환됨·제외)의 전이 규칙과, 전환된 Lead의 수정·삭제 잠금. 삭제 시 활동 종속 삭제(`AC-AT-05`)는 {{B30}}.

- Epic: {{E2}}
- 선행: {{B14}}
- 설명 포인트: 없음

## 유저 스토리

- `US-LD-3` 영업 담당자로서, 연락 중인 Lead를 "진행 중"으로, 가치가 확인된 Lead를 "검증됨"으로 표시하거나 가망 없음으로 제외하고 싶다.

## 인수조건

- [ ] `AC-LD-05` 전환되지 않은 Lead는 수정·삭제할 수 있다. 전환된 Lead는 수정·삭제가 거부되고 사유에 "전환된 Lead"가 포함된다 (BE / FE 표시는 {{F07}})
- [ ] `AC-LD-07` 상태는 다섯 값만 가진다. 등록 직후 "신규". 상태 변경은 02 §3.2 전이 표를 따르고 벗어난 전이는 `AC-COMMON-05` 형식으로 거부된다
- [ ] `AC-LD-08` "전환됨"은 전환 동작으로만 들어가는 최종 상태다. 상태 수정으로 직접 지정할 수 없고 벗어날 수 없다
- [ ] `AC-LD-09` 전환은 "검증됨"에서만 허용된다. 다른 상태의 전환 요청은 거부되고 아무 엔티티도 생성되지 않는다
