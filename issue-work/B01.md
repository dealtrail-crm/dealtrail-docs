## 배경

모든 CRM 요청은 로그인 세션이 있어야 한다. 테스트 계정과 회원 계정이 같은 세션 메커니즘을 쓰므로 Epic 1에서 먼저 만든다. 세션의 보관 수단(쿠키 등)과 식별자 형식은 API 계약 공통 규약({{C0}})에서 정한다.

- Epic: {{E1}}
- 선행: 없음
- 설명 포인트: 없음

## 유저 스토리

- `US-WS-4` 방문자로서, 브라우저를 닫았다가 돌아와도 로그인이 유지되길 원한다.
