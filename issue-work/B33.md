## 배경

대시보드 요약을 한 요청으로 돌려주는 집계 API. 변경 직후 즉시 반영, 0건 처리. 이 Epic의 설명 포인트 "파이프라인 집계"의 **핵심 이슈**다. 파이프라인 조회({{B28}})와 같은 규칙을 쓴다.

- Epic: {{E6}}
- 선행: {{B28}}, {{B31}}
- 설명 포인트: **파이프라인 집계 (핵심)**

## 유저 스토리

- `US-DB-1` 영업 담당자로서, 단계별로 얼마가 걸려 있는지 한눈에 보고 싶다.
- `US-DB-3` 방문자로서, 칸반에서 카드를 옮기면 대시보드 수치가 바로 바뀌는 것을 보고 싶다.
- `US-DB-4` 영업 담당자로서, 오늘 처리할 할 일과 지연된 건을 대시보드에서 바로 보고 싶다.

## 인수조건

- [ ] `AC-DB-01` 요약 조회 한 번으로 열린 단계별 건수·금액 합계, 열린 건 전체 건수·금액, 수주·실패 건수, 수주율, 지연 건수, 미완료 할 일 목록(지연·오늘 기한 구분)을 모두 돌려준다
- [ ] `AC-DB-02` 단계별 금액 합계는 그 단계에 현재 있는 열린 Opportunity의 금액 합이다. 종료 건은 어느 열린 단계에도 포함되지 않는다
- [ ] `AC-DB-04` 집계는 조회 시점 데이터를 반영한다. 단계 변경·생성·삭제 직후 다시 조회하면 즉시 반영된다 (지연이 생기면 ADR로 남긴다)
- [ ] `AC-DB-07` 집계 대상이 0건이어도 오류 없이 모두 0 또는 "계산 불가"로 돌려준다
- `AC-COMMON-15` 지연 판정의 "오늘"은 한국 시간 기준이다 (서버 계산 여부는 {{C6}})

## 구현 시 결정할 것 (ADR 소재)

- 매 요청 계산 vs 캐시·집계 테이블: 작업 공간당 상한 200건이라 매 요청 계산으로 충분한지, 측정값
- 반영 지연 허용 여부 (`AC-DB-04`). 지연이 생기면 ADR
- 지연 판정의 "오늘" 계산 위치(서버/FE)와 시간대 처리
