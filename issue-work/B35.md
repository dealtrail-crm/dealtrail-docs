## 배경

아이디·비밀번호만의 회원 가입과 로그인. 아이디 규칙·전체 유일성, 회원 세션 상한, 그리고 Epic 1의 작업 공간 규칙이 회원에게 그대로 적용됨을 테스트로 확인한다. 비밀번호 규칙은 {{B02}}, 세션은 {{B01}}.

- Epic: {{E7}}
- 선행: {{B01}}, {{B02}}, {{B07}}, {{B10}}
- 설명 포인트: 없음

## 유저 스토리

- `US-MB-1` 방문자로서, 며칠에 걸쳐 써 보고 싶을 때 아이디·비밀번호만으로 가입하고 싶다.
- `US-MB-2` 회원으로서, 가입 직후에도 예시 데이터가 들어 있는 CRM으로 시작하고 싶다.

## 인수조건

- [ ] `AC-MB-01` 아이디·비밀번호만으로 가입한다. 아이디 규칙(허용 문자·길이, 07 §3.1)을 벗어나면 `AC-COMMON-05` 형식으로 거부된다 (BE / FE 안내는 {{F22}})
- [ ] `AC-MB-02` 아이디는 전체에서 유일하다. 이미 있는 아이디나 테스트 계정 아이디로 가입하면 거부된다. 동시 가입 요청도 하나만 성공한다
- [ ] `AC-MB-03` 회원은 아이디·비밀번호로 로그인·로그아웃한다. 회원 세션 유지 기간 상한은 {{C7}}을 따른다 (BE)
- [ ] `AC-MB-05` 회원 계정으로 `AC-WS-12`~`17`(업종 선택·작업 공간 생성), `24`~`25`(초기화), `37`(상한) 시나리오가 통과함을 자동 테스트로 확인한다. 회원 작업 공간에는 만료 시각이 없다(`AC-MB-04`)
